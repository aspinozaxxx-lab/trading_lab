# AlgoPack: разрешение исторического конкурса и сохранения архива

2026-09-15. Пользователь ответил «разрешаю» на [конкретный запрос](
ALGOPACK_FAST_SCREEN_SCOPE_REQUEST_20260914.md) и дополнительно поручил скачать и
сохранить полезные данные AlgoPack до окончания оплаченной подписки, без новой оплаты.
Предыдущий authorization blocker снят. Старые документы/seals остаются историческими.

## Разрешённая работа

1. Один предварительный conditional historical конкурс трёх механизмов: давление
   потока на глубину, поглощение потока, изменение глубины. Информация2020–2025,
   без обучения final Ridge заново и без выдачи её in-sample результата за OOS.
   Протокол, формулы, controls, costs1×/2×, masks и входы фиксируются до результатов.
2. Сохранение доступной по текущей подписке истории AlgoPack для личного исследования:
   полный рынок EQ/FO/FX Super Candles, FUTOI, HI2 и доступные historical alerts.
   Перечень фактически доступных routes/периодов и полнота устанавливаются по API.
   Это разрешение на archival collection, не новый economic admission каждого набора.
3. Сбор/расчёты только gpu-mlserver, данные вне Git. Сохранять raw bytes, все поля,
   cursor/даты/schema, actual receipt, hashes и coverage. Пустые/недоступные периоды
   отличать от успешно загруженных; resume без повторного скачивания committed pages.
   Существующую четырёхконтрактную историю и её canonical результаты не изменять.

## Ограничения

- Защита2026 не отменена: все исторические запросы ограничены концом2025; никакие
  цены/доходности/labels/targets/PnL2026 не читать. Скачивание не даёт права открывать
  закрытый период. Current-only модули без исторического date filter не запрашивать.
- Final-vintage данные могли исправляться позднее: положительный preliminary PnL
  не доказывает original availability, реальную исполнимость или предсказуемые20–50%.
  Прежние source/model/live flags не повышать. Для прошедших нужен следующий уровень.
- Не покупать новую подписку, не менять тариф/автопродление, не подключать broker/live,
  не включать старый paper bootstrap и не запускать Windows collectors.
- Bearer token только из /etc/trading-lab/collector.env, только apim.moex.com по HTTPS,
  без redirect, token logs, отключения TLS или переноса credentials в Git/локально.
- [Ответ поставщика](ALGOPACK_VENDOR_REPLY_20260907.md) подтверждает личное использование,
  но отдельно не описывает сохранение прав после expiry. Не обещать безусловные
  post-subscription rights и не распространять архив. Новых писем/покупок нет.

Полная загрузка не объявляется завершённой по запуску сервиса или первому HTTP200.
Нужны фактический manifest всех planned jobs, hashes и отчёт missing/failed/empty.
Архив и economic конкурс — разные результаты; сбор данных не заменяет поиск стратегии.
