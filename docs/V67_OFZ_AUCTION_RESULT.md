# V67: покупка ОФЗ после аукциона — REJECT_STAGE1

2026-09-08. Единственный запуск завершён после публикации commit `4d7bbe2` и
[фиксированного протокола](V67_OFZ_AUCTION_CONCESSION.md). Отдельный механизм
предложен до его ценовых результатов: временное давление размещения на конкретный выпуск,
а не прежний агрегированный V20 score для фьючерсов.

Кандидата второго уровня нет. Относительное превосходство над контрольными облигациями
есть в этой выборке, но положительной абсолютной ценовой доходности после затрат нет.

## Результат на один пятисессионный эпизод

Сначала усредняются облигации одного публикационного дня, затем 157 таких дней.
Это средние **complete-case изменения чистых цен**, не годовой темп и не NAV портфеля.

| Показатель | Среднее |
| --- | ---: |
| Размещённая ОФЗ, до затрат | −0,0588% |
| Две контрольные ОФЗ, до затрат | −0,1714% |
| Разница с контролем | 0,1126% |
| Размещённая ОФЗ, базовые затраты | −0,2588% |
| Размещённая ОФЗ, удвоенные затраты | −0,4588% |

Базовые затраты — 0,10% на сторону, удвоенные — 0,20% на сторону.
Это заранее заданные исследовательские сценарии, не установленный тариф брокера.
Лучше падающего контроля не означает положительную доходность покупки.
Контроль не превращается задним числом в выбранную короткую позицию.

не независимая оценка достоверности и не вероятность будущего заработка.

## Полное покрытие

- Источник: 283 успешных primary аукционных результата ОФЗ-ПД.
- Выбраны до чтения будущих цен: 234 события. Ещё 41 не прошло требования к основной
  бумаге, у 8 не было двух подходящих контрольных выпусков.
- Полные пары входа/выхода: 232 события, объединённые в 157 публикационных дней.
- 2 выбранных события остались без полного окна внутри защищённой границы 2025 года;
  сохранены как `outside_source_window`, не заменены нулевой доходностью.
- Покрытие выбранных событий: 232/234 = 99,15%; от всех исходных событий — 232/283 = 81,98%.

Вход — следующий фактический TQOB день после публикации; выход — на пять общерыночных
сессий позже, без замены отсутствующей цены удобной более поздней. Отбор по ликвидности
и дюрации использует только доступный на момент решения срез. Новые источники не собирались:
на сервер перенесены только существующие auction parquet и manifest, 77 946 байт,
с теми же хешами; история ОФЗ уже была на сервере.

## Решение и границы вывода

Пройдены gates размера выборки, покрытия, среднего excess и положительных excess годов.
Провалены положительный net, положительные net годы и net t-stat:
`REJECT_STAGE1`. Окно, знак, ликвидность и контроль не перенастраивать по этому результату.
На второй уровень гипотезу не переводить.

CAGR, Sharpe и MDD портфеля — **N/A (null)**. Портфельных сделок — 0.
Купоны, НКД, финансирование, налоги, расчёты и общий капитал пересекающихся событий
здесь не моделировались; полного облигационного учёта ради провалившегося price screen
не добавляли. Поэтому вывод касается этой ценовой гипотезы, а не доказывает убыточность
всех облигационных стратегий. Источники current-vintage, не original publication vintages.
Цель предсказуемых 20–50% годовых не подтверждена.
